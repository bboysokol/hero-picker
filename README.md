# 💜 Gra dla Oli

Mała gra w przeglądarce (pod telefon): intro w terminalu → logowanie → quiz → łapanie serduszek → zdrapka → „Kochasz mnie?” → wyznanie.

- Wszystkie teksty: `config.js`
- Bez builda, bez zależności — czysty HTML/CSS/JS.

## Lokalnie

Otwórz `index.html` w przeglądarce.

## GitHub Pages

1. Wypchnij repo na GitHub.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
3. Po chwili gra będzie pod `https://<login>.github.io/<repo>/`.

> Uwaga: kod (a więc hasło i odpowiedzi) jest widoczny w źródle strony — to gra, nie sejf 😉
